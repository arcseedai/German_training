# Telc B2 Exam Trainer

A fully responsive, offline-capable, interactive web application to practice for the German Telc B2 language exam. 

---

## 🚀 Features

* **960 Practice Questions** across Reading (*Leseverstehen*), Language (*Sprachbausteine*), and Listening (*Hörverstehen*).
* **3 Test Formats**:
  * **Fast Test:** 30 questions (randomized from all sections).
  * **Reduced Test:** 60 questions (1 complete randomized Set).
  * **Original Test:** 105 questions (representing the length and sections of the official written exam).
* **Real-time answered counter** to track progress.
* **Bilingual Support:** Instantly toggle between German and English instructions.
* **Audio Transcripts & Audio Playback:** Text-to-speech option to read listening situations aloud in German.
* **Progress Backup:** Import and export your progress as a `.json` backup file to avoid data loss.

---

## 💻 How to Run Locally

### Desktop (Windows / Mac / Linux):
* **Option A (Easiest):** Simply double-click on `index.html` to open the app in any web browser.
* **Option B (Recommended for full compatibility):** Double-click `start_locally.bat` to launch a lightweight local server. This avoids strict browser security blocks on local files.

### Mobile (iOS / Android):
* Access it on the web using the deployed GitHub Pages link.

---

## 🌐 Deploying to GitHub Pages (For Mobile Use)

1. Upload this project folder to a public GitHub repository.
2. In the repository, go to **Settings** -> **Pages**.
3. Under *Build and deployment*, set the source branch to `main` (or `master`) and click **Save**.
4. Open the generated link on your phone!
